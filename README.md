# 🐟 What is AquaGrade?
<img src="https://github.com/Brhylle/AquaGrade/blob/main/src/frontend/src/assets/aq-1-fhd-with-logo.png">

**AquaGrade** is a deep learning model package designed for grading fish parts via drawing of bounding box on the region proposed by **YOLOv11 architecture**. It specializes in detecting and grading key parts of the fish such as the gills, eyes, and skin, based on industry standards like the FAO demerit pointing system.
